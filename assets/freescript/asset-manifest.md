# Asset provenance

- `logos/freescript-app-icon.png`: byte-for-byte copy of the real app icon in `build/icon-1024.png`.
- Logo SVGs: editable vector interpretation of the existing icon geometry; Courier wordmarks. Rendered transparent PNGs accompany them.
- `screenshots/*.png`: genuine Electron app captures using temporary storage and fictional screenplay text. No user library was accessed by the capture script. Includes PDF export, real PDF reimport, and continued editing.
- `promotional/*.png` (except the photograph): code-rendered brand compositions. Screens inside them are genuine app captures; surrounding type and layout are promotional design.
- `promotional/typewriter-campaign.png`: generated using the built-in image-generation tool on October 27, 2026. Campaign atmosphere, not a product screenshot. No external stock image or model/voice/music recording.
- `video/*.mp4`: silent motion compositions made from genuine app captures and brand layouts. These are edited workflow presentations, not continuous uncut screen recordings. Burned-in captions and WebVTT transcripts provide the sequence and limitations.
