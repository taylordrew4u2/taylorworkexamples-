The following examples are **illustrative only**. They are not promised features, completed client work, or agreed acceptance checks. Adapt only the examples that match the approved scope.

- **Request workflow:** Given a customer has supplied all required details, when they submit one booking request, then one request is recorded and the customer sees that it awaits confirmation. The interface does not describe a request as a confirmed appointment.
- **Validation:** Given a required field is missing, when the customer attempts to submit, then the field is identified, entered details are retained, and no incomplete request is sent.
- **Staff access:** Given an account has no staff permission, when it attempts to open the staff area, then it cannot see or change staff-only information.
- **Content editing:** Given an authorized editor has an approved content change, when they save it, then the agreed page shows that change on the supported screen sizes.
