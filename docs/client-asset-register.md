# 4u Digital client asset and access register

Use a separate copy alongside the [client kickoff template](client-kickoff-template.md) for each project. All fields are to be completed with the client. This template does not establish ownership, permissions, account access, or a launch commitment by itself.

Business correspondence: **admin@customtechbuilt4u.com**.

Do not put passwords, recovery codes, API secrets, private customer records, or payment details in this register or email them. Use the account provider's invitation controls for access. If an integration needs a secret, agree a secure transfer or secret-storage method with its account owner; record the method and owner here, never the secret itself.
