## Run locally

Requires Node.js 20 or newer.

```sh
npm ci
npm run dev
```

Open http://127.0.0.1:5173. The source uses standard HTML, CSS, and browser JavaScript. Run `npm run build` and `npm run preview` to inspect the complete statically generated service and project pages. There are no production dependencies, accounts, API keys, or database requirements.

## Verify and build

```sh
npm run check
npx playwright install chromium
npm run test:browser
npm run preview
```

`check` validates JavaScript syntax, project data, search/filter behavior, static SEO content, links, structured data, and builds the distributable site in `dist/`. Browser tests build the site and check desktop and phone interactions against the production build on an isolated preview port. `preview` serves the built site.
