# Portfolio preferences

- Use **4u Digital** as the public portfolio brand, with a small **by taylordrew4u** owner credit.
- Use the selected **Open frame** logo in `assets/4u-digital-logo-mono.png`; the current transparent master is `design/4u-digital/selected/open-frame-mono-master.png`, with its export record in `mono-manifest.json`.
- Use only black, white, and gray for new 4u Digital branding and future portfolio styling or custom illustrations. Never use red, purple, violet, lavender, lilac, magenta, blue, teal, or other chromatic accents. Keep project previews and galleries in their original full colors. Never apply grayscale or other recoloring filters to the work.
- Keep genuine project screenshots accurate to their original interfaces.
- Show authentic product icons beside project names, preserve their original colors and proportions, and explain what each project does in plain language. Use neutral text initials when no verified project icon exists.
- List only projects with a current public repository on `taylordrew4u2`'s GitHub. Remove unavailable projects from the catalog and opening previews rather than retaining older examples. Archived repositories remain eligible while publicly accessible.
